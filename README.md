# BountyScout

A GitHub issue scanner for micro bounties. Scans repositories for bounty opportunities and provides analysis including reward estimates, competition analysis, and Coding Agent fit assessments.

## Features
- Scan GitHub issues for bounty opportunities
- Analyze reward, effort estimation, and competition
- Support for multiple submission and payment methods
- Markdown-formatted reports with structured data

## Usage
Run scans against target repositories using the built-in scraper and analysis pipeline.
